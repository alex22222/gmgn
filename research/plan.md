# 研究计划：GMGN 扫链聪明钱包盈利方案

## 研究目标
从全网收集 GMGN 扫链聪明钱包的盈利方案，分析各类策略的风险收益比，洞察其中的可行机会。

## 背景
- GMGN 是一个链上数据分析和聪明钱包监控工具
- 用户希望了解如何基于 GMGN 数据进行扫链和跟随聪明钱包操作
- 需要评估不同策略的可行性和潜在风险

## 执行路线：Route A（Wide Search）

### Phase 1: 快速景观扫描（Quick Landscape）
- 5次搜索，从宏观到微观
- 搜索 GMGN 工具介绍、扫链策略、聪明钱包跟踪、盈利方案、风险分析

### Phase 1W: 多代理广泛探索（Multi-Agent Wide Exploration）
- 部署5-8个探索子代理，覆盖不同方面
- 每个子代理至少10次搜索

### Phase 2: 维度分解
- 基于Phase 1结果分解至少10个研究维度

### Phase 3: 并行深度挖掘
- 每个维度一个子代理，至少20次搜索

### Phase 4-5: 交叉验证与冲突解决
- 对比所有维度结果，分类置信度
- 解决冲突和薄弱点

### Phase 6: 洞察提取
- 跨维度分析，提取非显性洞察

### Phase 7: 报告撰写
- 加载报告撰写技能，生成最终报告
